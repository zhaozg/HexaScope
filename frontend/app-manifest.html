注册 HexaScope GitHub App

HexaScope 通过 GitHub App 授权读取你的公开数据并自动评估。App 注册仅需一次，注册后进入安装页一键安装即可。

一键注册（GitHub App Manifest）

点击下方按钮将跳转到 GitHub 注册页，确认后 GitHub 会自动创建名为 hexascope 的 App。

注册完成后会自动跳回回调页，展示 App 凭据（Client ID / Secret / Private Key）。凭据仅用于 Copilot 扩展等高级功能，本次安装评估无需在仓库中配置。

注册后

  1. 回到仓库首页点击 Install HexaScope 安装 App 到你的账户（或直接访问 github.com/apps/hexascope）；
  2. 安装即自动触发评估，约 1-2 分钟生成报告；
  3. 访问 ?user=你的用户名 查看六维能力雷达图。

也可以跳过 App，直接到仓库 Actions 页手动运行 HexaScope - 六维能力评估，输入自己的用户名（仅限本人）。
